# About Me

I'm a Full-Stack JavaScript Developer with experience designing, developing, and deploying web applications for clients across different industries. My work spans frontend and backend development using JavaScript, TypeScript, React, Next.js, Astro, Node.js, and various database technologies. I focus on building scalable, performant, and maintainable applications, integrating third-party services such as Stripe and Supabase, and developing backend APIs and serverless solutions using AWS.

Beyond application development, I also work on AI-powered solutions, including custom Model Context Protocol (MCP) servers and integrations with the Anthropic API to connect AI applications with external tools and data sources. I take ownership of the development lifecycle, from translating requirements and designing system architecture to infrastructure provisioning, CI/CD, deployment, and hosting management. My background in backend engineering and IT hardware support has also given me a practical understanding of troubleshooting, infrastructure, and building reliable technical solutions.

## Things I've Built

- **Property Management System** — A full platform for managing properties and bookings, featuring AI-generated offers powered by the **OpenAI API**, with **Stripe** handling payments and subscriptions.
- **NetSuite AI Assistant** — A conversational assistant for NetSuite, backed by a **custom MCP server** that exposes NetSuite data and operations as tools the AI model can call directly.
- **Continuous Learning & Iteration** — Constantly exploring new technologies, refining development practices, and improving existing solutions.
